# AtmoSync — Data Sources and Data Labelling

Every table in this project is labelled by origin. **No real dataset is bundled in the ZIP**; only the SIMULATED sample data is.

| Label | Meaning |
|---|---|
| SIMULATED | Generated by `scripts/generate_sample_data.py` / `simulator/` (seeded, reproducible). Not observations. |
| ASSUMPTION | A project simplification (see `docs/methodology/assumptions.md`). |
| DERIVED | Computed from a real dataset using stated assumptions (e.g. `ingestion/hab_prices.py`). |
| REAL | Unmodified observations from a published source (none bundled). |
